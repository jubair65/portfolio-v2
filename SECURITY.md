# Security Policy

If you find a security vulnerability, please report it privately. Do not open a public issue or pull request with proof-of-concept code.

## Reporting

Email <23201065@uap-bd.edu> with:

- A short description of the issue.
- Steps to reproduce (or a minimal repro).
- The affected URL, route, or commit if you can pin it down.
- Your suggested severity and any mitigation ideas.

I will aim to acknowledge the receipt within **3 business days** and respond with a plan within **7 days**.

## Scope

In scope:

- The deployed site at <https://jubair65.github.io> and any preview deployment under `*.vercel.app`.
- This repository's source code and configuration.

Thanks for helping keep the site safe.
